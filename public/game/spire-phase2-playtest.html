Summitbound — Phase 2: Playable Modular Terrain Test

Original v10 mountain geometry, with the existing PolePhysicsEngine and ice-step physics. Walk on generated rock/scaffold platforms, climb ice and ladders, and reach the orange deck. This is an isolated one-spire mechanics test; the final game engine and cross-spire jump course are not integrated.

Choose test spire

Controls

Left / Right (A/D) to run or alternate ice axes.

Up (W/↑) to attach and climb; Down (S/↓) to descend.

Space / POLE to plant while on a sufficiently wide platform, release to launch. This uses existing pole physics and doesn't guarantee a safe landing here.

Test state

The platform colliders are functional. Collision against the *entire solid rock outline*, animation integration, and physics-tested multi-spire jumps still require work. The character is a temporary drawn test avatar.
